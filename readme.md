# Evaluación 2: La Raiz que se Esconde

Universidad Católica del Maule - Lab evaluado 3

## Integrantes

Gonzalo Cerpa Salas

## Resumen

Este laboratorio se buscará resolver un sistema lineal denso de 12 incógnitas, cumpliendo a la vez 2 condiciones que compiten inversamente entre si, las cuales son:

- Costo operacional mínimo
- Máxima exactitud en la mantisa

Se nos pide tener la capacidad de argumentar numéricamente el compromiso elegido más que llegar a un resultado numerico.
